# floreva

Off Track is a modern fashion e-commerce store built with TanStack Start, React, Tailwind CSS and Lovable Cloud.

## Features

- Product catalog with categories (Men, Women, Kids, Shoes, Accessories and custom categories)
- Shopping cart, wishlist and checkout
- Arabic / English full localization (RTL + LTR)
- Prices in Egyptian Pounds (EGP)
- Admin dashboard: products, categories, orders and admin users
- Direct image upload for products
- Authentication via Email/Password and Google

## Development

```bash
bun install
bun run dev
```

The app runs on `http://localhost:8080`.
